# William Armitage — Portfolio 

A dependency-free personal portfolio built with semantic HTML, CSS and vanilla JavaScript. It is designed to publish directly through GitHub Pages.

## Run locally

From this directory:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Content and privacy

Employer work is deliberately described at a high level. The site does not publish internal architecture, proprietary screenshots, confidential performance figures or private contact information. Tournely is shown in more detail because it is an independently built product.

## Publishing

The site is published from the root of the `Armoooo/armoooo.github.io` repository with GitHub Pages. The custom domain is `williamarmitage.co.uk`.
